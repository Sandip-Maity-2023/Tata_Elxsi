⚡ 1. Data Prep & Physics

15% + 10% WEIGHT
Turbofan Sensor Pruning
Sensor Topology: 21 sensors across Fan, LPC, HPC, HPT, LPT modules.
Zero-Variance Drop: Sensors 1, 5, 10, 16, 18, 19 exhibit standard deviation = 0 across all runs. Pruned to remove rank deficiency.
Multi-Regime Normalization
Operating Regimes: FD002/004 vary across Alt (0-42k ft), Mach (0-0.84), TRA (20-100).
Centroid Clustering: K-Means (k=6) clusters operating states.
Regime Z-Score: Standardize per regime k: Z = (X - μ_k) / σ_k. Removes environmental flight swings while preserving pure physical degradation drift.
Denoising & Feature Engineering
Noise Filter: Savitzky-Golay / EWMA (α=0.2) removes high-frequency jitter without introducing phase lag.
Rolling Dynamics: Rolling mean, std, min-max over W=15, 30 cycles capture degradation velocity.
Trend d/dt: Linear slope over sliding windows isolates true monotonic degradation.
Thermodynamic Ratios: T30/P30 (combustor heat-pressure) & Ps30/Nc (HPC efficiency indicator).

🧠 2. ML Prognostics Engine

20% WEIGHT
Two-Stage Hybrid Pipeline
Stage 1 (Anomaly Detection): Unsupervised Isolation Forest + Mahalanobis Distance on nominal flight window to locate fault initiation (t_fault).
Stage 2 (RUL Estimation): Triggered once anomaly threshold is breached, eliminating premature wear penalties.
Piecewise-Linear RUL Target
Physics Cap (RUL_max = 125): Early engine operational life exhibits zero physical wear. Clipping avoids model learning noise during healthy cycles.
Linear Degradation: Degrades monotonically to 0 at failure cycle.
Model Algorithms & Justification
Primary - LightGBM Regressor: Sub-5ms inference, handles collinear rolling features, tree-based splits resilient to outliers.
Deep Alternate - 1D CNN + Bi-LSTM: Captures long temporal dependencies for FD004 benchmarking.
Imbalance Handling: Time-decay sample weights prioritize critical low-RUL cycles over nominal cycles.
NASA PHM'08 Asymmetric Loss
Penalty Formula: S = Σ (e^-d/13 - 1) for d < 0 vs Σ (e^d/10 - 1) for d ≥ 0 (where d = Pred - Actual).
Domain Reasoning: Late prediction risks in-flight failure; early prediction causes only early inspection. Late calls penalized 1.5x-2x heavier.
TreeSHAP Attribution: Interprets dominant sensor drift (e.g. HPC bleed temp).
